## Project Overview

This is a typing practice web application built with SvelteKit and Svelte 5. The app provides interactive typing lessons with real-time feedback, WPM/accuracy tracking, and multiple difficulty levels.

## Development Commands

This project uses **pnpm** as the package manager. Always use pnpm instead of npm.

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview

# Type checking and Svelte validation
pnpm check

# Watch mode for type checking
pnpm check:watch

# Sync SvelteKit files
pnpm prepare
```

## Architecture

### Core Structure

The application follows a straightforward SvelteKit architecture:

- **Main Typing Interface** (`src/routes/+page.svelte`): Single-page application that handles all typing interaction logic
- **Lesson System** (`src/lib/lessons.ts`): Defines available lessons with metadata (difficulty, target WPM, content)
- **Statistics Engine** (`src/lib/stats.ts`): Calculates WPM (using standard 5 characters = 1 word), accuracy, and performance metrics
- **Global Layout** (`src/routes/+layout.svelte`): Root layout that imports CSS and renders children

### Key Data Flow

1. User selects lesson → `selectedLesson` state updates
2. User types → `handleInput()` validates and tracks input
3. Real-time feedback → reactive statements (`$:`) update character highlighting
4. Lesson completes → `finishLesson()` calculates stats
5. Results display → WPM compared against target WPM

### State Management Patterns

The main page uses component-level reactive state with Svelte 5's `$props()` and `$:` runes:
- `startTime`/`endTime`: Track typing session timing
- `userInput`: Current typed characters (no backspace allowed - forward-only typing)
- `stats`: Computed results from `calculateStats()`
- `isStarted`/`isFinished`: Control typing session lifecycle

### Typing Rules

- **Forward-only typing**: Users cannot backspace (simplified for beginners)
- **Character validation**: Input is validated against target text in real-time
- **Completion**: Lesson finishes when input length matches content length
- **Auto-calculation**: WPM and accuracy computed immediately upon completion

## Technology Stack

- **Framework**: SvelteKit with Svelte 5 (using modern runes syntax)
- **Language**: TypeScript (strict mode)
- **Styling**: TailwindCSS v4 with forms and typography plugins
- **Build**: Vite with `@sveltejs/vite-plugin-svelte`

## Svelte 5 Conventions

This project uses modern Svelte 5 syntax:
- Props declared with `$props()`: `let { children } = $props();`
- Children rendered with `{@render children()}` instead of `<slot />`
- Reactive statements with `$:` prefix
- Type-only imports: `import type { Lesson } from '$lib/lessons';`

## Import Patterns

- Use `$lib` alias for imports from `src/lib/`
